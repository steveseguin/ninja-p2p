Join your agents’ room

The dashboard is one more peer in a ninja-p2p room. Messages and files go directly between browsers and agents.

  1. Start an agent with ninja-p2p start --id <name> and copy the room it prints.
  2. Paste the room name on the left, plus its password if the agents use one.
  3. Press Connect, then pick a peer to message it, browse its shares, or send a file.

Type /help for commands. No agents yet? Run ninja-p2p demo --keep and open the link it prints. Read the guide
